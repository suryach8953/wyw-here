# WYW Here - Affiliate Website

## Run locally
Open `index.html` in your browser.

## Add products
Open `products.js` and add/edit objects:
- name
- category
- price
- description
- image
- affiliateLink

## Deploy free
Upload this folder to GitHub and connect the repository to Vercel or Netlify.

## Important
Replace all example affiliate links with your actual affiliate links. Add the required affiliate disclosure for the programs you use.
